# Xtrim v46

## 在家改看网关，不再看网段

- 以前按本机 IP 网段判定「在家」：别人家也用同一网段（比如也是 10.10.1.x）时会被当成在家，守护随即断开 WireGuard，流量直连。现在在家只看一件事：**当前默认网关的 MAC 在不在受信任列表里**。网段谁都能撞上，网关 MAC 是自家路由器自己的地址。
- 判错时偏向「不在家」：网关不在列表、读不到 MAC、没有网关，一律按外部网络处理（守护连上 WireGuard）。
- 受信任网关可以有多个（比如第二套网络）。VPN 页「网络」卡的「这是家」开关就是信任 / 取消信任当前网关；点开卡片可以改名、移除，查看最近见过的网关（离开后也能补加信任）和每次网关变化的判定记录。
- 设置里的「受信任网络前缀」已删除。

## 守护与纯良合成一套

- 守护（出口调度）和纯良（出口不在时的兜底）守的是同一条线：去境外的包要么走可信出口，要么不出去。侧栏「纯良」磁贴改为「守护」，页面分为「出口调度」和「纯良兜底」两部分，纯良原有的设置、放行名单、运行信息都在。
- 纯良把网关代理算作出口，现在还要求网关是受信任网关：只有自家路由器且它上面的代理活着时，纯良才休眠。同样跑 fake-ip 代理的别人家不再让纯良放行。
- VPN 页信息卡改为：网络（含「这是家」开关）/ 守护（结论一行，点开进守护页）/ 流量 / 隧道。

## 升级须知

- **本版更新了后台服务**，首次打开会要求输入管理员密码升级。
- 从旧版升级后，旧的受信任网段不再算在家，只用来提示一次：在家第一次打开会先连上 WireGuard，并收到「受信任规则已改为网关 MAC」的通知。到 VPN 页「网络」卡打开「这是家」开关，即恢复在家断开。
- 路由器重刷固件后网关 MAC 可能改变（OpenWrt 的 br-lan 常是软件生成的地址），届时会按外部网络处理，再打开一次开关即可；也可以在路由器上固定 br-lan 的 MAC。

支持 Apple Silicon Mac、macOS 26 或更新。下载 `Xtrim-macOS.dmg`，将 Xtrim.app 拖入「应用程序」替换旧版。仍采用临时签名，尚无 Apple Developer ID 签名与公证。本版在本机构建打包后直接发布。

验证范围：
- 后台服务单元测试全部通过，包括「同网段、网关不同 → 不受信任」「读不到 MAC → 不受信任」「旧网段只提示不信任」「不受信任网关上的代理不算出口」。
- 在本机真实网络上读到网关与 MAC（有线、无线两条线都读到同一个路由器 MAC）；用隔离的后台服务副本走通信任、取消信任、改名、记录、错误输入。
- 翻译表缺译为 0。
- 未实测：安装版在别人家网络、路由器代理挂掉、WireGuard 断开空档这几种场景下的实际拦截与连接行为；新界面未逐页核对其他语言的排版。
