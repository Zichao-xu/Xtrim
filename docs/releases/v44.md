# Xtrim v44

## 纯良

- 网关透明代理在线时，也算作出口。你选的出口（WireGuard 或内置 mihomo）不在时，后台会再探测网关：如果网关在做 fake-ip 透明代理，境外流量本来就会被网关接走，纯良就保持休眠，不再拒绝境外直连。典型场景是在家时守护按设计断开 WireGuard，此前纯良会误判为「无出口」并接管。
- 判断全靠运行时探测，不看 Wi-Fi 名称，也不看是否在家。以下条件都满足才算网关代理在线：
  - 默认路由走物理网卡，且网关是局域网地址；默认路由走 utun（本机另有隧道或代理）时不算。
  - 直接向网关（不通再向 DHCP 下发的 DNS）解析一个境外域名，答案落在 fake-ip 段 `198.18.0.0/15`。
  - 出口网卡没有公网 IPv6，避免本机休眠后 IPv6 境外直连无人拦截。
- 网关代理在线后，单次探测失败先维持，连续两次失败才回到接管；所选出口恢复在线时，探测状态清零。
- 纯良页的出口显示为「网关代理 · 在线」，并附上所选出口不可用的原因和网关探测依据。

支持 Apple Silicon Mac、macOS 26 或更新。下载 `Xtrim-macOS.dmg`，将 Xtrim.app 拖入「应用程序」替换旧版。本版改动了后台服务：更新后打开 App，按提示升级后台服务。仍采用临时签名，尚无 Apple Developer ID 签名与公证。本版在本机构建打包后直接发布。

验证范围：
- 后台服务 Go 测试全部通过，新增网关代理探测（fake-ip 判定、utun 默认路由、公网 IPv6、非局域网网关、超时、迟滞）与出口回退测试。
- 本机实测：在家、WireGuard 按设计断开时，装上新服务后纯良由「接管中」转为「出口在线（网关代理），纯良休眠」，此前被拒的境外直连恢复正常。
- 未实测：离家网络、网关 mihomo 停止时回到接管只有单元测试覆盖，未在真实网络上验证。
