# Xtrim v45

## 多语言

- 界面文字全部走翻译表。此前翻译表停在 v1.0.11，之后新增的 900 多处中文直接写在代码里，切到其他语言时会中外混排；本版全部改为可翻译，9 种语言（English、繁體中文、日本語、한국어、Русский、فارسی、العربية、Türkçe、Tiếng Việt）补齐。
- App 内切换语言立即生效，不用重启。
- 后台服务返回的提示、错误和日志也会翻译：按整句匹配，主机名、配置名、数字等参数原样保留。日志页可切「原文」看中文原句；日志文件和诊断包仍是中文原文，方便对照排查。
- 产品专有名词统一译法：纯良 = Purity（日文、繁体中文用「純良」）。
- 成功 / 失败的判断不再依赖提示文字，切换语言后状态提示不会判错。
- 构建时自动收集新文字、补译并检查，Release 构建遇到缺译或绕开翻译表的写法会直接失败，以后新加的界面不会再漏翻。

## 界面

- 左侧滚动刻度改为每页同一位置统一绘制：不能滚动的页面也显示刻度（无当前位置、不可拖动），切页时刻度不再跳动；宽度跟随页边距档位。
- 图表绘图区高度改为档位 `layout.chartPlot`，可在调参面板调整。

支持 Apple Silicon Mac、macOS 26 或更新。下载 `Xtrim-macOS.dmg`，将 Xtrim.app 拖入「应用程序」替换旧版。本版未改动后台服务代码。仍采用临时签名，尚无 Apple Developer ID 签名与公证。本版在本机构建打包后直接发布。

验证范围：
- 翻译表缺译为 0，Release 构建的翻译检查通过；英文、日文抽查语义与格式符。
- 本机安装后实际切换语言查看主要页面。
- 未实测：阿拉伯语、波斯语的从右到左排版只做了编译与抽查，未逐页检查版面。
