# Xtrim v43

## 修复

- 桌面小组件的显示名改为 Xtrim。v42 中它仍显示为 WgSense，因此在聚焦搜索和小组件库里会出现一个名为 WgSense 的条目。

支持 Apple Silicon Mac、macOS 26 或更新。下载 `Xtrim-macOS.dmg`，将 Xtrim.app 拖入「应用程序」替换旧版。本版未改动后台服务，更新不会断开连接。仍采用临时签名，尚无 Apple Developer ID 签名与公证。本版在本机构建打包后直接发布。

验证范围：
- 本机 Release 构建与安装包检查；README 检查通过。
- 确认安装包内小组件的显示名为 Xtrim，后台服务与 v42 相同。
