# Xtrim v42

WgSense 更名为 **Xtrim**。App 不再只负责 WireGuard，而是管理几种互斥的出口，并在没有出口时守住流量。

## 更名

- App、菜单栏、小组件与安装包统一改为 Xtrim，安装包为 `Xtrim-macOS.dmg`，App 为 `Xtrim.app`。
- 配置、设置与后台服务沿用原有数据，升级后不需要重新导入或重新授权。
- 装好 Xtrim.app 后，请手动删除「应用程序」里的旧 WgSense.app。

## VPN：三个出口，一次只开一个

- 「VPN」板块合并原「概览」，顶部提供 WireGuard、Tailscale、mihomo 三个出口，点一下即切换，切换过程有即时反馈。
- Tailscale 尚在开发，点击仅提示。
- 磁贴与菜单栏徽章随出口显示对应标志。

## 内置 mihomo 内核

- 内嵌按固定提交编译的自建 mihomo 内核，由后台服务以 TUN 模式运行，接管本机流量与 DNS，退出时归还 DNS 设置。
- 配置通过 SSH 从路由器上的 mihomo 同步：只取配置与规则文件，转换为本机可用的形式，并在导入前离线校验；依赖路由器本地密钥的节点会被剔除并列出。
- 同步时一并沿用路由器上已选择的节点。
- 首次同步会带上 GEO 数据库，之后按需补齐。

## 纯良

- 原「出站拦截」独立为「纯良」板块与磁贴。
- 出口在线时休眠，不加任何规则；没有可用出口、出口失联或切换间隙时接管，只放行国内、局域网与放行名单，其余拒绝。
- 出口是否可用由后台每 3 秒判断：WireGuard 看握手，mihomo 看内核与控制接口。
- 「国内模式」可单独开启，与出口状态无关。

## 其他

- 原「代理」页更名为「面板」，出口为 mihomo 时自动接管本机内核；内置内核上的 SSH 相关功能为只读。
- 修复菜单栏面板首次打开时内容错位、只显示一角的问题。

支持 Apple Silicon Mac、macOS 26 或更新。本版改动了后台服务：更新后打开 App，按提示升级后台服务（会短暂断开连接）。仍采用临时签名，尚无 Apple Developer ID 签名与公证。

验证范围：
- 后台服务 Go 测试全部通过，覆盖出口切换、纯良休眠与接管、配置转换与导入、引擎锁顺序回归。
- 本机实测：WireGuard 与 mihomo 往返切换、从路由器同步真实配置、mihomo 出口下访问境外站点，纯良在出口在线时休眠。
- 未实测：mihomo 出口下偶发的延迟检测超时尚未排查；Release 构建与安装包未在发布前完整走一遍。
